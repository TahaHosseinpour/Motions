# استایل ink-dot — روایت مینیمال با «نقطهٔ جوهری»

> این فایل برای ایجنتی نوشته شده که **هیچ کانتکستی ندارد و ویدیوی رفرنس را ندیده**.
> هر چیزی که برای ساختن یک ریلز جدید در این سبک لازم است، همین‌جاست.

---

## ۱. ایدهٔ اصلی (روح سبک)

یک ریلز (عمودی ۹:۱۶ یا افقی ۱۶:۹)، روی **پس‌زمینهٔ مشکی**، با **خطوط نازک سفید** و **متن سفید**.
یک **نقطهٔ سفید توپر** («کاراکتر») از اول تا آخر ویدیو حضور دارد و قصه را «زندگی» می‌کند:
می‌پرد، می‌افتد، روی آب شناور می‌شود، روی نمودار بالا می‌رود، کوچک می‌شود.

- **راوی حرف می‌زند، تصویر جمله را کامل می‌کند.** تصویر نباید متن را تکرار کند (اگر می‌گوییم «ده تا نان»، عدد ۱۰ نمی‌نویسیم؛ ده نان می‌کشیم و نقطه رویشان می‌پرد و می‌شمارد).
- **هر بیت (beat) یک استعاره‌ی بصری** دارد: «ارزشش آب رفته» ← لیوانی که آبش نشت می‌کند و نقطه با سطح آب پایین می‌رود.
- **سکوت و فضای خالی** مهم‌تر از شلوغی است. حداکثر ۱ تا ۳ شیء در هر صحنه.
- **اشکال گویا**: همیشه به‌جای شکل انتزاعی، شکلی را بکش که مفهوم را فوری منتقل کند (نان = برش نان تُست، نه کپسول؛ پول = اسکناس با قاب و مدالیون؛ قیمت = نمودار با محور). شکل‌ها line-art ساده‌اند ولی **قابل‌شناسایی**.

## ۲. زبان بصری

| مورد | مقدار | توضیح |
|---|---|---|
| بوم صحنه‌ها | 1080×1920، 30fps (مختصات صحنه همیشه این است) | `core/types.ts` |
| خروجی | `portrait` 1080×1920 یا `landscape` 1920×1080 | `story.format` — بخش ۳ |
| بزرگ‌نمایی | کل نقاشی ×1.25 (`T.scale`) | صحنه‌ها با مقیاس ۱ نوشته می‌شوند |
| تم | `dark` (پیش‌فرض) / `light` (کاغذ کرم قدیمی) | `story.theme` — `THEMES` در `theme.ts` |
| پس‌زمینه | `#0D0D0D` + گرین خیلی ملایم + ویگنت | `T.paper` |
| جوهر (خط/نقطه/متن) | `#F4F1EA` سفید گرم | `T.ink` |
| خط کم‌رنگ | `rgba(244,241,234,.45)` | `T.inkSoft` — جزئیات داخلی، لیبل‌ها |
| پرکننده | `rgba(244,241,234,.18)` | `T.fill` — آب، سطح، حجم |
| **سبز** | `#3FBF74` | `T.good` — فقط ✓، رشد مثبت، «درست» |
| **قرمز** | `#F05A4E` | `T.bad` — فقط ✕، از دست رفتن، «غلط» |
| **هایلایت زرد** | `#FFD84A`، متن روی آن مشکی | `T.highlight` / `T.markText` |
| ضخامت خط اصلی | 3.5px، سر و گوشه گرد | `line()` |
| خط ظریف | 2px | `line(T.thin)` |
| نقطه (کاراکتر) | شعاع 15px، توپر سفید | `T.dotR` |
| فونت روایت و لیبل‌ها | preset از `core/fonts.ts`: `dast-nevis` (پیش‌فرض) یا `iran-yekan`؛ کپشن 76px | `T.font` — `story.font` |
| فونت عدد/UI | IRANYekanX FaNum (اعداد فارسی) | `T.fontSans` |

**رنگ‌ها را هیچ‌وقت در صحنه hard-code نکن** و `T.*` را در ثابت‌های سطح ماژول کپی نکن — Reel قبل از رندر تم/فونت story را روی `T` اعمال می‌کند (`applyStory`)؛ همین باعث می‌شود تم و فونت بدون دست زدن به صحنه‌ها عوض شوند.

**قانون رنگ:** ۹۵٪ ویدیو تک‌رنگ (سفید روی مشکی) است. سبز و قرمز فقط وقتی «معنا» دارند (تیک، ضربدر، سود/زیان) و هر بار حداکثر روی یک یا دو شیء.

**هایلایت زرد:** در هر کپشن حداکثر **یک** کلمه/عبارت کلیدی را با `*...*` علامت بزن (مثلاً `"*ده تا* نون می‌خریدی."`). ماژیک بعد از ظاهر شدن جمله از راست به چپ کشیده می‌شود. هایلایت روی همان چیزی برود که تصویر نشانش می‌دهد (عدد، مفهوم، کلمهٔ تضاد).

**فونت دست‌نویس:** تقریباً هیچ حرف لاتینی ندارد → متن انگلیسی ننویس (اگر لازم شد با `T.fontSans`). Bold ندارد → برای تأکید از هایلایت استفاده کن، نه وزن.

**عوض کردن فونت/تم بدون تغییر کد:** در story.json `"font": "iran-yekan"` یا `"theme": "light"`، یا فقط موقع رندر:
`npm run render -- <p> --font iran-yekan` (خروجی جدا: `<p>-iran-yekan.mp4`). فونت جدید = فایل در `assets/fonts` + یک family و یک preset در `core/fonts.ts`.

## ۳. ترکیب‌بندی (Layout)

صحنه‌ها همیشه در مختصات 1080×1920 کشیده می‌شوند؛ `Reel.tsx` (`LAYOUT`) آن را روی قاب خروجی می‌گذارد.

**عمودی (`portrait`، پیش‌فرض)** — مختصات صحنه:
```
y≈530   ── جای کپشن بالا   (captionPos: "top"، روی خروجی y=430)
y≈720   ── جای «خانه»ی نقطه وقتی بالای اشیاء می‌نشیند
y=920   ── مرکز ناحیهٔ نقاشی (T.cx=540, T.cy=920) — شیء اصلی این‌جا؛ بزرگ‌نمایی ×1.25 حول همین نقطه
y≈1300  ── جای کپشن پایین  (captionPos: "bottom"، روی خروجی y=1400)
```
چون نقاشی ×1.25 بزرگ می‌شود، شیء‌ها را در صحنه حدوداً بین y=620 تا 1220 و x=160 تا 920 نگه دار.

**افقی (`landscape`)** — نقاشی سمت چپ قاب (مرکز صحنه → x=640, y=560)، کپشن‌ها در ستونی سمت راست (x=1440، وسط ارتفاع).
`captionPos` در افقی نادیده گرفته می‌شود؛ پس همان story.json بدون تغییر در هر دو فرمت رندر می‌شود.

- همه‌چیز وسط‌چین. حاشیهٔ افقی حداقل ۱۴۰px (UI اینستاگرام).
- هیچ چیزی پایین‌تر از y≈1500 نرود (کپشن و دکمه‌های اینستاگرام).
- کپشن‌ها را بین بالا/پایین **جابه‌جا کن** تا ریتم داشته باشد؛ وقتی شیء بلند است کپشن را سمت مقابل بگذار.
- **راست‌به‌چپ:** گذشته سمت راست، آینده سمت چپ؛ شمارش از راست شروع می‌شود؛ نقطه در خط زمان از راست به چپ حرکت می‌کند. (استثنا: نمودار قیمت/زمان قراردادی چپ‌به‌راست است.)

## ۴. حرکت (Motion)

- **خطوط خودشان را می‌کشند** (`draw(p)` با stroke-dashoffset)، ۱۵ تا ۳۰ فریم.
- اشیاء کوچک با **pop** (اسکیل 0→1 با `ease.back`) ظاهر می‌شوند، پشت‌سرهم با فاصلهٔ ۲–۵ فریم.
- **نقطه هیچ‌وقت ناپدید نمی‌شود و نمی‌پرد بین صحنه‌ها**: سیستم در ۱۲ فریم اول هر بیت نقطه را از آخرین مکان بیت قبلی نرم به مکان جدید می‌برد (`BLEND` در `Reel.tsx`). پس هر صحنه فقط می‌گوید نقطه «الان» کجاست.
- حرکات نقطه فیزیکی‌اند: پرش سهمی (`hop`)، سقوط با شتاب (`ease.in`)، شناوری با سینوس ملایم.
- خروج صحنه: ۸ فریم آخر همه‌چیز به‌جز نقطه fade می‌شود (`exitFade`). صحنهٔ آخر fade نمی‌شود.
- کپشن: کلمه به کلمه با fade + کمی بالا آمدن + blur؛ سپس هایلایت زرد؛ ۶ فریم آخر محو.
- Easing پیش‌فرض: `ease.inOut` (0.65,0,0.35,1). هیچ حرکت خطی بی‌حس.

## ۵. ریتم و نوشتن داستان

- هر بیت **۲ تا ۳.۵ ثانیه**؛ یک جملهٔ کوتاه (حداکثر ~۸ کلمه). جملهٔ بلند را با `\n` دو خط کن (هیچ کلمه‌ای تنها در خط دوم نماند).
- ساختار پیشنهادی: **قلاب** (یک موقعیت آشنا) ← **تضاد** (چیزی عوض شد) ← **گره** (چرا؟) ← **نام‌گذاری مفهوم** ← **جمع‌بندی احساسی/کاربردی**.
- لحن محاوره‌ای و ساده («می‌خریدی»، «همون پول»).
- برای مفاهیم انتزاعی، یک **شیء ملموس روزمره** پیدا کن (نان، لیوان، کیف پول، ساعت، پله…).

## ۶. فرمت story.json

```json
{
  "title": "عنوان",
  "style": "ink-dot",
  "format": "portrait",            // یا "landscape" — اول کار از کاربر بپرس
  "font": "dast-nevis",            // اختیاری: "iran-yekan"
  "theme": "dark",                 // اختیاری: "light"
  "audio": "voice.mp3",            // اختیاری؛ نسبت به پوشهٔ پروژه
  "beats": [
    { "scene": "bill", "seconds": 2.2, "captionPos": "bottom",
      "caption": "متن روایت", "props": { } }
  ]
}
```
مجموع `seconds` = طول ویدیو.

**وقتی صدا داریم:** `npm run transcribe -- inputs/voice.mp3 --project <p>` یک `story.draft.json` می‌سازد:
هر جمله (بر اساس مکث‌ها) یک بیت، با `seconds` دقیقِ هماهنگ با صدا و `audio` تنظیم‌شده.
فقط `scene`/`props`/`captionPos` را پر کن و کپشن را تمیز کن (نقطه‌گذاری، `*هایلایت*`، `
`) — **`seconds` را تغییر نده** وگرنه از صدا جلو/عقب می‌افتد.
اگر یک جمله برای یک صحنه زیادی طولانی است، با `npm run sentences -- <p> --max-words 7` دوباره جمله‌بندی کن.
زمان دقیق هر کلمه در `transcript.json → sentences[].words` هست (برای هم‌زمان کردن یک حرکت با یک کلمهٔ خاص).

## ۷. کتابخانهٔ صحنه‌ها (`scenes/`)

| scene | چه می‌کشد | نقطه | props |
|---|---|---|---|
| `bill` | اسکناس با قاب و مدالیون | ظاهر می‌شود داخل مدالیون (مثل پرتره) | `value` (عدد گوشه) |
| `loaves-buy` | ۱۰ برش نان در ۲ ردیف | از راست به چپ روی ستون‌ها می‌پرد و با هر فرود ۲ نان «خریده» می‌شود | — |
| `loaves-loss` | ۱۰ نان؛ چندتا ✕ قرمز می‌خورند، می‌لرزند، می‌افتند | بالای ردیف، با افتادن کمی پایین می‌رود | `lose` (پیش‌فرض ۳) |
| `timeline` | محور زمان RTL با دو تیک و لیبل | از «گذشته» (راست) به «حال» (چپ) می‌رود، رد پا می‌گذارد | `from`, `to` |
| `equal` | دو اسکناس یکسان + «=» + ✓ سبز | روی هر دو می‌پرد و روی = می‌نشیند | `right`, `left` |
| `leak` | لیوان پر که از ته چکه می‌کند | روی سطح آب شناور است و با آن پایین می‌رود | `from`, `to` (۰..۱) |
| `chart` | محور + منحنی صعودی + خط‌چین راهنما | سر منحنی سوار است | `yLabel`, `xLabel`, `curve` |
| `shrink` | حلقه‌های رو به بیرون + تیک روزها | ثابت در مرکز، با هر روز کوچک‌تر | `days` |
| `asset` | یک تصویر doodle ساخته‌شده (بخش ۸) با reveal | بالا/کنار تصویر | `id`, `w`, `h`, `reveal`, `dot` |

**قطعات آماده (`primitives.tsx`):** `Bill`, `Loaf`, `Cross` (✕ قرمز), `Check` (✓ سبز), `glassPath`.

## ۸. اَسِت‌های تصویری (وقتی line-art کد کافی نیست)

بیشتر چیزها را با SVG در کد می‌کشیم. ولی وقتی مفهوم به **آدم، حالت، احساس یا شیء پیچیده** نیاز دارد
(آدمکی که تعجب کرده، نانوایی، کیف پول باز، صف خرید…) یک اَسِت تصویری لازم است.

**قانون طلایی:** هر تصویر باید با **کاراکتر شیت** `reference/character-sheet.png` ساخته شود.
همیشه شیت را همراه پرامپت به مدل تصویر بده — هیچ‌وقت فقط با متن تصویر نساز. سبک شیت: doodle ماژیکی سیاه،
آدمک‌های سرگرد با چشم نقطه‌ای، ضخامت خط یکسان، بدون سایه و رنگ، پس‌زمینهٔ سفید خالص، بدون متن.
پرامپت پایهٔ سبک در `assets.config.json` است.

**روند:**
1. در `PLAN.md` پروژه بنویس کدام بیت به چه تصویری نیاز دارد و چرا.
2. `outputs/<project>/assets.json`:
   ```json
   { "assets": [
     { "id": "shopper", "beat": 4, "subject": "a stick figure holding one banknote, staring surprised at a tiny shopping bag",
       "notes": "worried face, three small motion lines above the head" } ] }
   ```
   `subject` انگلیسی، کوتاه، یک سوژه، بدون متن داخل تصویر.
3. `npm run assets -- <project> prompts` → `outputs/<project>/assets/PROMPTS.md` + کپی شیت به نام `_reference.png` کنار آن.
   (یا `generate` اگر API تصویر تنظیم شده — شیت خودکار ضمیمه می‌شود.)
4. تصاویر را با نام `assets/<id>.png` ذخیره کن (پس‌زمینهٔ **سفید خالص**).
5. `npm run assets -- <project> check` → وضعیت را چک می‌کند و جدول Assets در `PLAN.md` را آپدیت می‌کند.
6. رندر. تا وقتی تصویری نیست، جایش یک کادر خط‌چین با اسم asset دیده می‌شود (رندر خراب نمی‌شود).

**در ویدیو:** سفیدیِ تصویر خودکار شفاف می‌شود (فیلتر alpha = A − روشنایی) و خطوط روی کاغذ می‌نشینند.
- صحنهٔ آماده: `asset` — props: `id`، `w`/`h` (پیش‌فرض 560)، `reveal`: `wipe` (راست به چپ، مثل کشیدن) | `pop` | `fade`،
  `dot`: `top` | `left` | `right` | `hide` | `{x,y}`.
- داخل صحنه‌های سفارشی: `<AssetImage id x y w h p reveal />` از `core/AssetImage.tsx`.
- نقطه همچنان قهرمان است: کنار/بالای تصویر می‌ماند (فقط وقتی واقعاً لازم است `hide`).
- تصویر جایگزین روایت نیست؛ همان قانون «تصویر جمله را کامل می‌کند» برقرار است.

## ۹. ساختن صحنهٔ جدید (وقتی هیچ صحنه‌ای مناسب نیست)

۱. اول دنبال **استعارهٔ بصری** بگرد: مفهوم ← شیء روزمره ← کاری که نقطه با آن می‌کند.
۲. فایل `scenes/<name>.tsx` بساز:

```tsx
import React from "react";
import { draw, ease, exitFade, tween } from "../../../core/anim";
import { SceneDef, T, line } from "../theme";

export const myScene: SceneDef = {
  // f = فریم محلی بیت، dur = طول بیت به فریم، p = props
  Visual: ({ f, dur, p }) => (
    <g opacity={exitFade(f, dur)}>
      <circle cx={T.cx} cy={T.cy} r={200} {...line()} {...draw(tween(f, 0, 24))} />
    </g>
  ),
  // جای نقطه در هر فریم (نقطه را در Visual نکش!)
  dot: (f) => ({ x: T.cx, y: T.cy - 200 - T.dotR, r: T.dotR }),
};
```
۳. در `scenes/index.ts` ثبتش کن (کلید kebab-case) و در جدول بالا اضافه‌اش کن.
۴. شکل‌های قابل‌استفادهٔ دوباره را به `primitives.tsx` ببر.

**چک‌لیست کیفیت هر صحنه:**
- [ ] بدون کپشن هم معنی می‌دهد؟ (تصویر خودش قصه را می‌گوید)
- [ ] شکل‌ها گویا هستند (نه دایره/مستطیل بی‌معنا)؟
- [ ] نقطه کاری «انجام» می‌دهد، نه فقط ایستادن؟
- [ ] حداکثر ۳ شیء، فضای خالی کافی، به کپشن برخورد نمی‌کند؟
- [ ] رنگ فقط برای ✓/✕ یا سود/زیان؟
- [ ] RTL رعایت شده؟

## ۱۰. اجرا

```bash
npm run studio                               # پیش‌نمایش زنده (کامپوزیشن ink-dot)
npm run render -- <project>                  # outputs/<project>/story.json → <project>.mp4
npm run render -- <project> --still 120      # یک فریم PNG برای چک سریع
npm run render -- <project> --format landscape   # نسخهٔ افقی → <project>-landscape.mp4
npm run render -- <project> --font iran-yekan    # فونت دیگر بدون تغییر story/کد
```
رندر طول می‌کشد: ایجنت خودش رندر اجرا نمی‌کند؛ دستور را به کاربر می‌دهد.
بعد از رندر، از چند لحظه فریم بگیر و نگاه کن (ffmpeg) — مخصوصاً برخورد اشیاء با کپشن، در هر دو فرمت.
